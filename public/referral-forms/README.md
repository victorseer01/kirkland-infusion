# Referral form PDFs

Drop each medication's referral form here as a PDF named after the medication,
lowercased with spaces turned into hyphens:

- `tepezza.pdf`
- `simponi-aria.pdf`
- `remicade.pdf`
- `rituxan.pdf`
- …etc.

Once a file is present, that medication on the **For Physicians → Referral
Forms** section links directly to its downloadable form. Medications without a
PDF here fall back to the shared Google Drive folder automatically. No code
change needed — the site picks up new files at build time.
